# Resume

Standalone resume site for [John Berger](https://johnberger.dev). Edit `content/resume.md` and deploy.

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Share

Point other projects at the deployed URL (Vercel, GitHub Pages, or a custom domain like `resume.johnberger.dev`).
